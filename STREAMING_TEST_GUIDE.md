## 🎯 **Пошаговое тестирование:**

### **Шаг 1: Генерация ключа для стримера**
1. Открой: `http://localhost:3000/ai-reactions/generate`
2. Введи имя стримера: `teststreamer`
3. Нажми "Generate AI Reaction Keys"
4. Скопируй Store Link: `http://localhost:3000/ai-reactions/store/teststreamer`

### **Шаг 2: Настройка Overlay в OBS/Streamlabs**
1. Открой OBS Studio или Streamlabs
2. Добавь новый источник "Browser Source"
3. Вставь URL: `http://localhost:3000/overlay?token=teststreamer`
4. Установи размер: 1920x1080 (или под свой стрим)
5. Включи "Interact" для взаимодействия

### **Шаг 3: Тестирование AI Tasks**
1. В overlay нажми кнопку "Next" 
2. Должно появиться AI задание
3. Нажми кнопку голоса (🔊) для озвучивания
4. Попробуй разные тона: Funny, Serious, Chill, Street

### **Шаг 4: Тестирование AI Reactions**
1. Открой Store Link в новом окне: `http://localhost:3000/ai-reactions/store/teststreamer`
2. Выбери стиль реакции: Support, Light Troll, Hard Troll
3. Нажми "Buy Reaction" ($2.99)
4. Заполни тестовые данные Stripe
5. Реакция должна появиться в overlay с голосом!

## 🚨 **Возможные проблемы и решения:**

### **Overlay не загружается:**
- Проверь URL: `http://localhost:3000/overlay?token=teststreamer`
- Убедись, что сервер запущен: `npm run dev`
- Проверь консоль браузера на ошибки

### **AI Reactions не работают:**
- Проверь Store Link: `http://localhost:3000/ai-reactions/store/teststreamer`
- Убедись, что Stripe настроен
- Проверь логи сервера

### **Голос не воспроизводится:**
- Проверь, что OpenAI API ключ настроен
- Убедись, что кнопка голоса включена
- Проверь консоль на ошибки аудио

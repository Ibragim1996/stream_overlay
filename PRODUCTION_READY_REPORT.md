## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Технологии:
- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS
- **AI**: OpenAI GPT-4o-mini, TTS API
- **Database**: Redis (Upstash)
- **Payments**: Stripe
- **Auth**: Firebase
- **Deployment**: Vercel

### API Endpoints:
- `/api/token` - Генерация токенов
- `/api/task` - Генерация AI задач
- `/api/voice/*` - Синтез голоса
- `/api/ai-reactions/*` - AI реакции
- `/api/stripe/*` - Платежи

### Переменные окружения:
- `OPENAI_API_KEY` - OpenAI API ключ
- `OVERLAY_SECRET` - Секрет для оверлея
- `UPSTASH_REDIS_*` - Redis конфигурация
- `STRIPE_*` - Stripe конфигурация
- `FIREBASE_*` - Firebase конфигурация

## 🚀 ИНСТРУКЦИИ ПО ДЕПЛОЮ

### Вариант 1: Vercel (Рекомендуется)
1. Идите на [vercel.com](https://vercel.com)
2. Создайте новый проект
3. Подключите GitHub репозиторий
4. Настройте переменные окружения
5. Деплойте!

### Вариант 2: Ручная загрузка
1. Используйте архив `ai_stream_new_production_ready.tar.gz`
2. Распакуйте на сервер
3. Установите зависимости: `npm install`
4. Настройте переменные окружения
5. Запустите: `npm run build && npm start`
